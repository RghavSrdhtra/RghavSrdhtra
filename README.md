## Featured Projects

### [NexCommand (Crisis Response Dashboard)](https://github.com/RghavSrdhtra)
A centralized emergency management dashboard built for rapid incident tracking and resource dispatch.
- Visualizes incoming emergency events and automatically recommends the closest response units.
- Connects to Google's Gemini Flash model to produce tactical summaries for operators under pressure.
- Built with a low-latency, dark glassmorphism interface to keep information readable during high-stress situations.
- **Stack:** JavaScript (ES6+), Gemini Flash API, CSS, Vite

### [SilkSphere (Smart Sericulture System)](https://github.com/RghavSrdhtra)
An agricultural monitoring setup combining IoT sensor telemetry and deep learning for silkworm farmers.
- Employs a custom PyTorch CNN for early disease identification and automated cocoon grading.
- Ingests environmental telemetry (temperature, humidity, air metrics) transmitted over MQTT.
- Includes a React dashboard providing farmers with real-time analytics and threshold alerts.
- **Stack:** Python, PyTorch, C++, MQTT, React 18

### [Multimodal Classification Template](https://github.com/RghavSrdhtra)
A PyTorch framework built to process and classify multimodal data streams.
- Combines image data with structured text features using late-fusion neural architectures.
- Includes modular preprocessing pipelines with Pandas and NumPy, plus evaluation visuals in Plotly.
- **Stack:** Python, PyTorch, Pandas, NumPy, Plotly

### [Generative Workflows, Audio & Security](https://github.com/RghavSrdhtra)
- **Local GenAI & Media Pipelines:** Custom ComfyUI workflows for image and video synthesis, plus Whisper-based speech transcription and TTS tooling.
- **AI Intrusion Detection (AI IDS):** Machine learning models applied to network telemetry for anomaly and intrusion detection.
- **Stack:** Python, ComfyUI, Whisper, OpenCV, Scikit-learn
